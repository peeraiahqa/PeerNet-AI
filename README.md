# 📖 Overview

PeerNet AI is a modern AI-powered networking platform that combines Artificial Intelligence with Networking and Automation.

It helps engineers troubleshoot network issues, generate automation scripts, prepare for interviews, analyze uploaded documents, and build IEEE-compliant test plans.

Whether you're learning networking or working on enterprise SD-WAN deployments, PeerNet AI is built to increase productivity.

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/peeraiahqa/PeerNet-AI.git
```

Go to the project directory

```bash
cd PeerNet-AI
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```

---

# 🔑 Environment Variables

Create a `.env` file and add:

```env
OPENAI_API_KEY=your_openai_api_key

SUPABASE_URL=your_supabase_url

SUPABASE_KEY=your_supabase_key
```
